# Limitations

- This runtime does not inspect model weights.
- It does not prove hidden human-feedback residue is absent globally.
- It does not inspect provider internals.
- It does not guarantee complete interface inventory without independent witness.
- It is boundary-relative, TCB-relative, and witness-relative.
- `AutonomyAssessment` is a scoped runtime assessment, not a global statement
  that an agent has become fully self-originating or free of all inherited
  training influence.
- `completeClaim` is exceptional and normally unavailable for local-only runs.
- Rollback does not erase information release, external logs, observations, or
  downstream decisions.
- Open-ended semantic judgment must be retained authority, residual risk,
  ordinary evidence, or routed to a stronger tier.
